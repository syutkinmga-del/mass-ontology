## What this candidate adds

- Generic `maritime:Vessel`, preserving `mass:MASSVessel` and `nav:TargetShip` compatibility without treating all target ships as autonomous.
- `bh:Trajectory`, `bh:TemporalUnit` and Position/Speed/Course physical-state descriptions. `TemporalUnit` is an information segment distinct from `time:ProperInterval`.
- SOSA/SSN `Observation`, PROV-O provenance, timestamp differentiation, and QUDT 3.5.3 quantity values using `qudt:hasUnit`.
- Versioned 370-triple **synthetic AIS-like** demonstration (six source records, 18 observations, three time segments, and explicit coverage gap). Original P04-03 fixture retained unchanged.
- Formal SHACL, Python, independent ROBOT/HermiT and negative mutation testing; exact multiset bindings for BH-CQ-01, BH-CQ-02, BH-CQ-03.
- T-04 publisher RDF snapshots pinned by SHA-256; independent CI workflow via `make behavior-test`.

## Limits, DEFERRED work and terms

- This release candidate has **synthetic**, prevalidated AIS-like observations; no raw AIS stream decoder, real-world vessel prediction accuracy, human-vessel decision authority or navigation safety certification is established.
- BH-P05 (spatial/semantic reasoning, GeoSPARQL and named pre-/post-inference graphs) and BH-P09 (behavior recognition prototype) are **DEFERRED**.
- No full BFO/CCO equivalence, production `owl:imports` of external vocabularies, verified W3ID resolution, COLREG compliance inference or remote ROC/VTS control is claimed.
- MASS-SK-1.0 was verified for **source byte/manifest integrity**, not newly parsed under a SysML v2 Pilot Implementation.
- Direct Python dependencies and ROBOT JAR are pinned; transitive Python wheels and exact JDK patch artifact are not fully hash-locked.
- The `VERSION` and Python project metadata label the **target** candidate and do not indicate a published release. The project-owned `LICENSE`, third-party notices and project-owner sign-off remain mandatory release gates. External T-04 RDF snapshots retain their independent rights.
