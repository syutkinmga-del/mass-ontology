## Included in the BH-P04 profile

- Generic `maritime:Vessel` with compatibility references to `mass:MASSVessel` and `nav:TargetShip`, without treating ordinary observed targets as autonomous ships.
- `bh:Trajectory` and `bh:TemporalUnit` as **information records**, with `time:ProperInterval` modelled separately; Position, Speed and Course physical-state descriptions.
- SOSA/SSN observations, QUDT 3.5.3 quantities using **`qudt:hasUnit`**, OWL-Time timestamps/intervals, and PROV-O provenance.
- Versioned **370-triple synthetic AIS-like fixture**: six source records, 18 SOSA observations, three temporal units and a deliberate 12:02–12:04 UTC coverage gap.
- SHACL validation, Python tests, independent ROBOT/HermiT checks, deterministic SPARQL competency questions, negative mutation tests and legacy regression coverage.
- Eight locally pinned T-04 external RDF snapshots and corresponding attribution / license records.

## Research limitations and deferred work

**Not claimed or certified:** live/raw AIS message decoding, measured vessel position prediction accuracy, safety-critical autonomy, COLREG compliance, operational navigation authority, operational ROC/VTS control, or field validation. No verified full BFO/CCO equivalence, production OWL imports, public W3ID dereference test or SysML v2 parser conformance is claimed. MASS-SK-1.0 was checked for **exact source bytes**, not re-parsed against a SysML v2 implementation. Direct Python dependencies and the ROBOT JAR are pinned; transitive wheels and exact JDK builds are not fully hash-locked.

**DEFERRED:** BH-P05 (spatial and semantic behavior reasoning / GeoSPARQL) and BH-P09 (behavior recognition prototype).
